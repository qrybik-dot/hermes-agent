Known non-blocking issues

• Telegram сеть периодически деградирует/reconnect; в логах есть отдельный Event ... bound to a different event loop на send retry. Gateway остаётся жив. Это отдельный network/runtime хвост, не вызван improvement-loop.

• Hermes CLI startup сам по себе может занимать несколько секунд; event-dispatcher поэтому не «мгновенный», но запускается только по изменению pending-директории.

• Upstream same-card request_review всё ещё не terminal в kanban_stop.py. Мы его не патчим: финальная схема архитектурно его не использует.
