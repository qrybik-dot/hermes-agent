1. Главный результат

Flash Agent включён точечно
Автоматически получает только безопасные запросы с несколькими шагами: найти, прочитать, сравнить, преобразовать и подготовить итог.
Большие документы пока не переключены
Роль быстрого извлечения подготовлена, но автоматический флаг оставлен выключенным. Сначала собираем фактические результаты agentic-пилота.
Почему это безопасно: новая роль не получает terminal, не перехватывает VPS, код, календарь, travel и исследования, а отключается одной строкой конфигурации.

4. Отказоустойчивость

Основной канал
Flash Agent через Antigravity/CLIProxy.
Независимый резерв
GPT‑5.5 через Codex при quota, auth, provider, timeout или model-not-found.

Разрешён максимум один fallback.

Fallback допускается только до первого tool-call.

Контекст изолируется, инструменты резервной модели отключены.

Глобальный fallback-движок старых ролей специально не переписывался.

7. Что дальше

Собираем 20–30 реальных agentic-задач и сравниваем завершение, задержку, лишние tool calls, ошибки и пользовательские исправления.

Если пилот успешен
Оставляем Flash Agent основной agentic-моделью и отдельно включаем быстрый long-context extraction.
Если есть регресс
Отключаем один флаг. Все прежние роли продолжают работать без миграции и восстановления данных.
